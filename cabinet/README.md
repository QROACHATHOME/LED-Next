# Real cabinet config

The arcade machine's actual `cabinet.json` (panel layout + wiring), panel photo and log are copied
here at the end of a cabinet session, so the development PC can use the real layout.

To use it on the dev PC: copy `cabinet.json` (and the photo) into
`src/LedNext.App/bin/Debug/net8.0-windows/config/` and start the app.
